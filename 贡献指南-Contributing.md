# Contributing

Small fixes, clearer installation steps, and regression tests are welcome. Describe the observed problem and expected behavior in an issue or pull request.

Run `npm test` with Node.js 22 or 24 before submitting. Tests must use synthetic data and mocked service boundaries: never send real email or require a contributor's private Notion token. Preserve sending-disabled defaults, HTML escaping, safe error messages, complete pagination, and daily delivery protection.

Use English for public documentation and email templates. Standard metadata filenames remain conventional; substantive source and test filenames use Chinese-English names to follow this project's workspace convention. Do not submit personal configuration, copied private source material, or third-party code without its required attribution and license.
